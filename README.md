## Task

The goal of this project was to create a web application that displays a list of Pokémon, allows users to search for specific Pokémon, and view details about each Pokémon. The challenge included implementing lazy loading for fetching Pokémon data, handling search functionality, and styling the application to provide a user-friendly experience.

## Description

This project is a React application that interfaces with the Pokémon API to fetch and display data about Pokémon. Key features include:

- **Lazy Loading**: Pokémon data is loaded incrementally as the user scrolls down the page to enhance performance and user experience.
- **Search Functionality**: Users can search for Pokémon by name using a search bar, which filters results dynamically.
- **Detailed View**: Users can click on a Pokémon to view more details on a separate page.
- **Styling**: The application is styled with modern CSS to ensure a visually appealing and responsive design.

The project uses React for building the user interface and Axios for making HTTP requests to the Pokémon API. It also leverages React Router for navigation between the homepage and detail pages.

## Installation

To set up this project locally, follow these steps:

1. **Clone the Repository**:
    cd pokemon-app (e.g. to change to the project directory)

2. **Install dependancies**:
    npm install
    npm start

## Usage
**Search for Pokémon:** Use the search bar at the top of the homepage to find specific Pokémon by name. As you type, the list of Pokémon will be filtered to match your query.

**View Pokémon Details:** Click on a Pokémon card to navigate to the detail page, where more information about the Pokémon will be displayed.

**Infinite Scrolling:** Scroll down the homepage to load more Pokémon data automatically as you reach the bottom of the page.

**Navigate Between Pages:** Use the browser’s back and forward buttons or the navigation links to move between the list of Pokémon and individual Pokémon details.
